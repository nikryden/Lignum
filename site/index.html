Built for the logs other tools give up on

Everything goes through a line index and positional reads, so the file is never loaded into memory.

Huge files, instantly

The first screen shows at once while the index builds in the background. The scrollbar grows as it goes.

Search that keeps up

Plain text or regex, in parallel, with progress and cancel. Search one file, every open tab, or a whole folder.

Filters that compose

Include and exclude rules, hide non-matching lines, and search inside the filter. Results stream in while indexing runs.

Highlight rules

Color whole lines by level or by any regex, with separate colors for light and dark themes, and presets.

Syntax coloring

Open a .cs, .json, .py or .yaml file and it is colored like in your editor. Edit, import and export schemes.

Bookmarks with notes

Five colors, notes with links, and a bookmarks pane. Export the log with your notes as a .lm package to share.

Safe for live logs

Opens files with full sharing, never locks or writes them, and shows a reload banner when the file changes.

Picks up where you left

Tabs, scroll positions and filters come back on the next start. Open a whole folder with Ctrl+Shift+O.

Comfortable to read

Detail pane, light and dark themes, zoom, font and tab width, and automatic encoding detection with an override.

Bring your own AI

Lignum is an MCP server. Turn on AI access and GitHub Copilot, Claude, Cursor, Codex and other tools can search your open logs, read lines, and add filters, highlight rules and bookmarks for you.

  • Off by default. Nothing is shared until you turn it on.
  • The AI runs in your own tool. Lignum needs no API key.
  • Every call is listed, and permissions decide what the AI may do.
  • No AI tool can ever change a log file.

Questions

How big a file can Lignum open?

It is designed and benchmarked for files of 2 GB and more. Lignum keeps only a list of line offsets and the lines on screen in memory, so the limit is your disk, not your RAM.

Can I read a log that a service is still writing?

Yes. Lignum opens files with full read, write and delete sharing, so it never blocks the writer or log rotation. When the file changes, a banner offers to reload it.

Which encodings are supported?

UTF-8 with or without BOM, UTF-16 LE and BE, and Windows-1252. The encoding is detected automatically, and you can override it from the status bar.

Installer or portable?

The MSI adds Lignum to the Start menu and can open .log and .lm files with a double-click. The portable Lignum.exe is a single self-contained file you can run from anywhere.

Where are my settings stored?

As JSON files in %APPDATA%\Lignum. Lignum does not use the registry for settings.
