# 04: Double-click the margin to toggle a bookmark

**What to build:** Double-clicking in the line-number margin to the left of a row toggles a bookmark on that line, the same as Ctrl+F2. This works in the main view and in the results pane, where it bookmarks the original line.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Double-click in the margin toggles the bookmark for that row (view-model test for the line chosen)
- [x] Double-click in the text area keeps its normal behaviour (word selection)
- [x] In the results pane it bookmarks the original line number
